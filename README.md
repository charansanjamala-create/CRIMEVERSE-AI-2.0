# 🛡️ CRIMEVERSE ENTERPRISE 2.0
**Unified Crime Intelligence & Autonomous Case Management Platform** *(Built for Smart India Hackathon 2026)*

### ✨ Key Modules & Features
- **Agentic AI & Investigation Operations:** Automated case management, Challenge AI, and What-If Simulation modules.
- **Crime Network & Geospatial Analysis:** Interactive criminal entity correlation graphs (14+ network nodes) and tactical location mapping.
- **Cyber & Threat Intelligence:** Integrated **VoiceShield AI**, **MailGuard**, **VeriTrust AI**, and **ChainTrace AI** for multi-channel fraud detection.
- **Real-Time Command Center:** Live CCTV wall, supervisor escalations, evidence locker, and incident velocity analytics.

### 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (Vite)
- **Backend & AI:** Python, Flask, Pandas, NetworkX
